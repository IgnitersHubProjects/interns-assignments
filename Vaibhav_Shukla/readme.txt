This repository contains solutions to the Python challenges given during my internship.
Each challenge focuses on a different concept of Python programming and is written in a simple and easy-to-understand way.

Challenge 1: Approximate Search

In this challenge, I created a program that suggests k similar words based on user input.
The program reads words from a text file and uses Python’s difflib library to find close matches.

Why this was done:
To understand approximate string matching and how suggestions work in search systems.

Challenge 2: Arithmetic Expression Solver

This program reads arithmetic expressions from a file, solves them one by one, and writes the answers into an output file.
It supports basic operators and brackets.

Why this was done:
To practice file handling and evaluating expressions using Python.

Challenge 3: Email Trigger Program

In this challenge, I wrote a script to send an email programmatically with required details and an image attachment.
Due to security restrictions on Gmail and Outlook, a local SMTP server was used to demonstrate email triggering.

Why this was done:
To learn how email automation works and understand real-world security limitations.

Challenge 4: String Reverse & Palindrome Check

This program takes a string from the user, reverses it using slicing, and checks whether it is a palindrome.

Why this was done:
To practice basic string operations and conditional logic.


I took help from Google and Stack Overflow whenever I got stuck, mainly to understand errors and improve my approach.
These tasks helped me improve my Python basics and problem-solving skills
