# Igniters Hub Internship Assignment

Solutions for the 4 challenges completed by Ayush Sharma.

## Structure
- `Challenge-1-Email/` : Script to send email with image attachment using Nodemailer.
- `Challenge-2-Palindrome/` : Palindrome checker.
- `Challenge-3-BinarySearch/` : Binary search implementation on sorted array.
- `Challenge-4-StringManipulation/` : Word count, word reversal, and space replacement.

## How to Run

### Challenge 1 (Email)
```bash
cd Challenge-1-Email
npm install
# Add your email credentials in a .env file (see .env.example)
node sendEmail.js
```

### Challenge 2 (Palindrome)
```bash
cd Challenge-2-Palindrome
node palindrome.js
```

### Challenge 3 (Binary Search)
```bash
cd Challenge-3-BinarySearch
node binarySearch.js
```

### Challenge 4 (String Manipulation)
```bash
cd Challenge-4-StringManipulation
node stringManipulation.js
```
