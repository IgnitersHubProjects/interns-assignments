# interns-assignments



# 🔄 Approximate Searcher

- reads input from text file
- sort the word based on its similarity with given keyword
- returns top K matching words

# 🔄 Expression Evaluator

- reads Arithmetic expression from input text file
- evaluate the expression using an exp4j (an open source library)
- throws invalid expression error for invalid expressions
- write result along with expression in new output text file

# 🔄 Email Sender

- Uses Java Mail API to send email

# 🔄 Palindrome Checker

- A simple java program that checks if a string reads the same forward and backward.
