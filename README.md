\# Igniters Hub – Python Programming Assignment



This repository contains my solutions to the four mandatory programming challenges assigned as part of the Igniters Hub internship selection process.



\## Challenges



\### Challenge 1: Approximate Word Search

\- Loads words from a text file into memory.

\- Accepts a word from the user.

\- Uses Levenshtein Distance to find similar words.

\- Returns up to three suggestions for misspelled words.



\*\*Files:\*\* `main.py`, `words.txt`



Run:

```bash

python challenge\_1\_approximate\_search/main.py

```



\### Challenge 2: Arithmetic Expression Evaluator

\- Reads mathematical expressions from an input file.

\- Evaluates expressions with operator precedence.

\- Supports addition, subtraction, multiplication, division and exponentiation.

\- Supports parentheses and implicit multiplication.

\- Writes the calculated results into an output file.



\*\*Files:\*\* `main.py`, `input.txt`, `output.txt`



Run:

```bash

python challenge\_2\_expression\_evaluator/main.py

```



\### Challenge 3: Automated Email Sender

\- Sends an email using Python SMTP.

\- Uses Gmail SMTP with SSL.

\- Includes sender details in the email body.

\- Attaches an image to the email.

\- Uses environment variables to keep email credentials out of the source code.



\*\*Files:\*\* `main.py`, `image.png`



Run:

```bash

python challenge\_3\_email\_sender/main.py

```



Required environment variables:

\- `SENDER\_EMAIL`

\- `EMAIL\_APP\_PASSWORD`



\### Challenge 4: Palindrome Checker

\- Checks whether a given string is a palindrome.

\- Ignores capitalization, spaces and punctuation.

\- Compares the normalized string with its reverse.



\*\*File:\*\* `main.py`



Run:

```bash

python challenge\_4\_palindrome/main.py

```

\- Recursive descent parsing

\- SMTP email automation
