# Python Internship Assignments

## Overview

This repository contains Python programs developed as part of the internship coding assessment. It includes four programming challenges focused on basic Python concepts, problem-solving, and algorithms.

## Challenges

### 1. Approximate Search
- Reads a collection of words from a text file.
- Stores the words in memory.
- Accepts a word from the user.
- Finds and displays similar words as suggestions.

### 2. Arithmetic Expression Evaluation
- Reads mathematical expressions from an input text file.
- Evaluates the expressions.
- Writes the calculated results into an output text file.

### 3. Palindrome Checker
- Accepts a string from the user.
- Checks whether the string reads the same forward and backward.
- Displays whether the string is a palindrome.

### 4. Binary Search
- Implements the binary search algorithm.
- Searches for a target element in a sorted array.
- Displays the index if the element is found.

## How to Run

1. Clone this repository:

```bash
git clone https://github.com/chamyalpooja075/interns-assignments.git
```

2. Open the project folder in Visual Studio Code.

3. Open the folder of the challenge you want to run.

4. Run the Python file:

```bash
python main.py
```

5. Follow the instructions displayed in the terminal.

**Note:** For Approximate Search, keep `words.txt` in the same folder as `main.py`. For Arithmetic Expression Evaluation, provide the expressions in `input.txt`.
